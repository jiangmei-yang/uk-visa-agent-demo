# 先回答申请入口和步骤，再问必要信息

2026-09-05。这次修复直接针对普通来信：“先别一直问我个人信息，告诉我英国
旅游签证在哪个网页申请、怎么开始。”同义英文也必须得到有用答复，而不是只有
收件回执、泛化拒答或另一个姓名问题。

## 原因与处理

原入口匹配能识别 `apply → website/link`，却漏掉 `which webpage → apply`
及已经明确访问签证语境下的 `How do I get started?`。此外，合法但不理想的
`unsupported` 或 `next_step` 提案会压过现有的审核式申请说明。单改模型提示
不能解决最终编排层的这个问题。

现在统一识别当前、可核验的普通申请入口请求：同一组原文片段同时用于提案
归一、无提案时的审核式回答、回答的上下文和来源处理。原模型提案的原文、
置信度不修改；完整提案含资格、保证获批、费用时长等限定时，不因为截取其中
的安全关键词就将其洗成普通申请问题。引用、条件、转述、别人的申请，以及
其他签证路线的前文仍保留作用范围。

“先别问个人信息”是一项本轮沟通偏好，不等于暂停档案、撤回处理许可或确认
申请摘要。它不吞掉同封独立的申请问题，也不阻止正常保存新提供的事实。
如果客户明确允许这封询问某个个人问题，仍保留这项当前请求；未来或引用中的
允许不覆盖现在的偏好。下一封普通事实回复可以恢复正常必要信息收集。

申请答复提供官方页面、Apply now、在线填写、保存后继续和签证中心预约步骤，
按段落展开，不再以“这是入口说明”的元说明结束。说明保持条件性，不声称已经
判定客户必须申请 Standard Visitor。没有要求链接时仅去掉 URL，不删掉步骤。

仍区分“我想办英国签证，怎么开始”这种未明确路线的首询：它保留原先的一般
路线和准备情况说明，不被强行替换成某类签证申请入口。已明确访客／旅游签证
语境后的无主语续问则可以得到申请步骤。

测试另外发现，带有“不要讲申请步骤”的十年签证费用请求可能在提案被过滤后
误走六个月费用。已在费用回答本身保留有效期限限定：长期类别指向官网 Visa fees
表中对应行，不套用六个月金额。本轮没有新增或宣称支持完整长期费用金额表。
