# 普通旅游咨询的资料校验修复

真实 Gmail 演示使用的是获准发送的虚构客户资料。原邮件已经说了旅游、自费和日期
未定，回复却追问出行目的。原档案中 `visit_purpose` 和 `funding_source` 均为空。

在本地用相同原句复现：即使给校验器正确的模型候选值，也会被丢弃。

- “想今年11月去伦敦旅游一周”省略主语，未匹配目的校验的肯定计划表达。
- “具体哪天还没定，费用自己承担”把日期的不确定性错误传播到独立的资金来源。

修复扩展了有明确英国/伦敦目的地的省略主语表达；只从资金来源的前置不确定性判断中
排除完整、独立的日期未定短句。没有取消来源、所有者、否定、条件、引用或资金选择检查。
测试包含原句、日期顺序、其他人的话、假设、否定及真正不确定的资金来源。

100 项相关回归测试通过，包含跨两轮数据库重开和实际发送器的捕获测试。
Ruff 与 mypy 通过。一次新的真实 DeepSeek 调用中，模型提出旅游和自费，校验也保留
两项；本次使用 5,842 tokens。这不是多次稳定性或总体准确率证明。

修复后在 Gmail 网页发送普通纠正回复，没有改写数据库，也未补造同意或确认。
