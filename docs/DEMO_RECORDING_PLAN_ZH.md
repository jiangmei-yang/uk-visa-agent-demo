# Gmail 完整流程演示录制方案

## 交付物

- 6–8 分钟主片：客户视角为主，少量后台证据说明。
- 未剪辑原片：保留真实收发和等待，便于追溯。
- GitHub README 中的运行入口、视频链接和已知限制。

当前状态：录制准备，不是已完成视频。尚未验证真实 Gmail 最终材料包到达
收件端，不能用离线页面或合成邮件代替这个镜头。

## 开拍前

1. 用专门的虚构申请案例，使用已授权的测试邮箱；隐藏私人邮箱列表、头像、
   通知、其他客户信息。关闭邮件通知弹窗，录制指定窗口区域，不录整个桌面。
2. 冻结并记录源码提交及实际运行版本。检查 Gmail worker、模型连接、收件
   注册范围和人工复核入口；离线 console 与 Gmail 必须指向各自真实数据，
   不得用一个无关 Demo 档案冒充这封邮件对应的档案。
3. 实际邮箱使用人先完成资料处理授权。不能代填同意、数据库改状态或剪掉
   未完成授权后声称流程成功。片中可简短说明已经完成授权。
4. 完整彩排一次：直到测试客户邮箱确实收到 ZIP，下载并检查内容。
5. 预先标明哪些等待会快进，实际人工复核动作不能隐藏成模型自主决定。

## 主片镜头

| 时间 | 画面与操作 | 要证明的能力 |
| --- | --- | --- |
| 0:00–0:25 | “通过邮件准备英国访客签证材料”，说明虚构案例、不提交申请 | 范围清楚 |
| 0:25–1:15 | 客户普通主题来信，描述旅游/会议计划和未定日期；展示实际回复 | 无特殊触发词，先回答需求 |
| 1:15–2:10 | 客户分两次补充资料；问一个官方申请入口；再次说明日期未定 | 有用回答、少追问、记住已知和未定信息 |
| 2:10–3:20 | 分批发虚构材料；实际发现日期冲突或缺翻译；展示具体补件建议 | 基于文件检查，不直接宣称齐全 |
| 3:20–4:15 | 客户发纠正文件；展示旧文件被替代、当前档案更新 | 纠错可追溯，不丢历史、不串案 |
| 4:15–5:15 | 展示需要的人工复核；客户读当前摘要并明确确认 | 模型不能自行批准或替客户确认 |
| 5:15–6:15 | 实际复核后发送；切到客户收件箱下载 ZIP，打开摘要、清单、索引和附件 | 真实交付结果，而非聊天结束 |
| 6:15–7:15 | 展示一次重复来信不重复处理的证据；简述状态、校验、重试隔离 | 稳定性设计 |
| 7:15–8:00 | GitHub、启动方式、已验证范围及 WhatsApp 仅接口的限制 | 面试官可复现 |

时间仅为剪辑预算，不要求系统在此时限内回复。只可压缩等待，不得跳过失败、
伪造发件时间或把不同客户的结果拼成一次成功流程。

## 客户自然来信参考

不要机械照抄。演示者可用自己的话表达相同场景，答案由实际系统生成。

邮件主题使用“英国旅游签证咨询”或“英国会议签证材料”，正文不加 TEST、
VISA-DEMO 编号、SYNTHETIC TEST ONLY 或 PROFILE CONFIRMED 等工程口令。
虚构案例说明放在视频开场及 README，虚构材料本身保留明确标识，不能让
演示证件被误用。客户直接说“信息都正确，可以继续”即可；是否构成有效
确认仍须由当前摘要、待确认问题和实际工作流判断，不能靠这句话跳过复核。

顾问回复沿用“具体问题—原因—下一步”的方式，例如指出邀请函结束日期
比行程晚一天，请客户确认行程或补新版邀请函。不要把内部状态、测试编号、
模型版本塞进业务回复。一般咨询先回答；个人资料处理的必要说明单独适时
呈现，不冒称真人，也不把资料授权和最终材料确认混为一谈。

- “你好，我是中国护照，在香港读书，想下半年去英国旅游一周，日期还没定。
   我应该先准备什么？”
- “日期还没确定，先别追问这个。我想先看看官方申请入口，只给链接就行。”
- “学校这周开不了证明，我有学生系统导出的 PDF，可以先看看缺什么吗？”
- 后续提供与虚构文件一致的信息，再故意提供一份可追溯的日期修正。

不要在材料或回复中编造真实护照、银行资料、资金来源或隐瞒风险。案例的
信息完整度由系统实际要求决定，不能只因镜头时间到了就强行结束收集。

## 录制与成片检查

本机 macOS 的 `screencapture` 帮助已确认支持视频和区域录制；尚未验证实际
录屏权限或生成任何视频。先做短片试录，检查可读性、裁切、光标和声音。
默认不录麦克风，旁白后补；不能意外录入房间对话。

- 所有客户信息和附件均为虚构，私密账户区域不入镜。
- 字体在 1080p 播放时能读清，不长时间展示终端日志。
- 必须看到最终包真正到达客户邮箱，且文件能打开。
- 不称“100% 准确”“保证获签”“全自动批准”。
- 不把预设回放、数据库夹具或剪辑动画标为真实 Gmail/真实模型操作。
- 录制失败时先修复并重新彩排，不用旁白掩盖断点。
