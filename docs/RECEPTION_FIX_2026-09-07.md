# 接待开场修复

客户只问“你是谁”时，旧的回复直接询问出行目的，没有回答身份问题。

现在将简短问候、身份和服务能力询问作为接待语处理，介绍英国签证咨询服务以及可提供的帮助，再询问客户想咨询什么。不冒称真人或持牌顾问；客户直接询问是否真人或自动化助手时，如实回答。

匹配仅针对当前回复全文。带具体问题的问候、个人信息、引用历史以及附带新文件的消息不会被接待语吞掉。既有材料核查、确认和交付条件不变。

验证包括接待中英文、引用隔离、具体问题保留、真实身份回答、档案不变，以及经过 Gmail 发信前最终检查的连续对话回归。集成测试使用隔离数据库和捕获传输，不代表本次已向真实邮箱发送新邮件。

本次修改不代表全部产品已达到满分。之前的模型评测及 91beddb 容器构建对应修改前的源码，不能作为本次完整版本验证。
