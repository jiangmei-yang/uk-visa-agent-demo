# Footer-only trailing page repair

Complete inspection of the retained sponsor QA PDF found two pages, not the one
claimed in the previous note. The first page contained all 25 rows; the second
contained only the standard frame/footer. The earlier visual check did not inspect
the complete page inventory. That claim is corrected in the original report;
the original PDF is retained unchanged rather than overwritten with a repair.

The production `_pdf` builder appended a three-millimetre `Spacer` after its final
table. At the page boundary the table fit, but the otherwise purposeless spacer
overflowed onto another page. Removing the trailing spacer fixes this without
changing the table padding, body text, source facts or business gates.
